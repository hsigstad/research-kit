guides cited in `../writing_style.md`. Stored locally so the rule file's
references resolve even when offline and so URL rot doesn't lose them.

The Head reference is stored as a paraphrased summary (`.md`) rather than
a PDF — it's a blog post, and a structured summary is the natural form
for web content. The other PDFs are the authors' own copies.

Two Weingast files are kept: the iconic 2-page original *Structuring Your
Papers (Caltech Rules)* (1995) and the 4-page expanded *How to Structure
Your Paper and Write an Introduction* (rev. 2010), which is a superset with
fuller introduction-writing guidance.

When updating `writing_style.md` with rules drawn from these sources, the
extraction lives in the rule file; these references stay as the
authoritative originals to cross-check against.
