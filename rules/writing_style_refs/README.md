# Writing-style references

Vendored copies of canonical economics-writing guides cited in
`../writing_style.md`. Stored locally so the rule file's references
resolve even when offline and so URL rot doesn't lose them.

The Head reference is stored as a paraphrased summary (`.md`) rather than
a PDF — it's a blog post, and a structured summary is the natural form
for web content. The other three are stored as the authors' own PDFs.

When updating `writing_style.md` with rules drawn from these sources, the
extraction lives in the rule file; these references stay as the
authoritative originals to cross-check against.
