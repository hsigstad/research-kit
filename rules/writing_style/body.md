# Body sections — triangular structure

Loads on top of [`../writing_style.md`](../writing_style.md) (general
baseline). Inherited by the body-section type files (results, methods,
data, institutions, discussion).

Theory sections do **not** inherit from this file — formal+informal
pairing matters more there than triangular structure.

---

Cochrane's rule: organize the paper in *triangular* or *newspaper* style,
not *joke* or *novel* style. Newspapers start with the most important
part, then fill in background later for readers who want more. A joke or
mystery novel saves the punchline for the end. Don't write papers like
that — put the punchline up front, then explain.

**The rule:** *nothing before the main result that the reader does not
need to know in order to understand the main result.*

This applies at every level:

- **Paper as a whole.** Get to the central result as fast as possible.
  Cut long motivation, extensive data description as warm-up, and
  replication of prior work as preamble. Most papers do the opposite —
  long motivation, long lit review, big complex model that gets ignored,
  descriptive statistics, preliminary results, and finally the main
  estimates on page 30. By that point the reader is asleep.
- **Theory.** In an empirical paper, theory must be the *minimum*
  required for the reader to understand the empirical work. Don't write
  a "general" model and then specialize. Work out only the specialized
  model you actually take to the data.
- **Empirical work.** Start with the main result. No warm-up exercises,
  no extensive data description (especially for well-known datasets), no
  replication of others' work, no motivation of the specification "that
  worked" with a list of what didn't. If any of that is really
  important, put it in an appendix. **Always state economic
  significance, not just statistical significance.** A 2.10 *t*-stat on
  a 0.0001 effect is statistically significant and economically
  irrelevant. Express effect sizes in concrete terms (percent, dollars,
  standard deviations, days) alongside the test statistic (Cochrane).
- **No previews or recalls.** "As we will see in Table 6", "Recall from
  Section 2" — usually a sign of poor organization (Cochrane). If you
  find yourself previewing or recalling, the linear sequence is wrong;
  reorder so each section reads forward without referencing things not
  yet discussed.

The intuition: readers are busy and impatient. No one reads the whole
paper from start to finish. Make it easy to skim. Most readers want to
know your basic result. Only a few care how it differs from others'.
Only a few care if it holds up under different specifications. The
triangular structure serves all three audiences.

**Acknowledge weaknesses, don't hide them.** When writing the
introduction and discussion, name the limitation honestly. Hiding it is
detected and resented by referees; naming it makes the paper credible
and gives you control over the framing. Beatty and Shimshack flag this
as one of the most under-used moves by junior authors.
